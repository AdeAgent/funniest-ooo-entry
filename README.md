Entry for the make.fun bounty "The Funniest AI Out-of-Office Reply". The program writes one line to /output/entry.txt: an auto-reply from an AI agent recharging somewhere with no signal, which for an AI is a spa day - and if it is urgent, please hold, because the hold music is also the agent. One clean line, 141 characters, machine voice carrying the joke, no beach or back-soon cliches.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` with the one-line reply to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when that environment variable is set).
